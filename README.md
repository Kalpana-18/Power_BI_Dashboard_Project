# Power_BI_Dashboard_Project
# 📊 Sales Dashboard - Monthly (Power BI Project)

This project is a **Sales Dashboard** designed using **Power BI** to visualize and analyze key performance metrics for monthly sales. It provides interactive insights into product performance, customer behavior, and category-wise sales trends.

---

## 🔧 Tools & Technologies Used

- **Power BI Desktop**
- **Excel** (for data input)
- **DAX** (Calculated Measures and KPIs)
- **Data Modeling**

---

## 🎯 Objective

To create a dynamic and visually intuitive dashboard that tracks and analyzes:
- First Sales & First Profit
- Discount performance
- Sales by Product Category/Sub-Category
- Customer-level Product Purchase Trends

---

## 📌 Key Features

### KPIs at a Glance
- 💰 **First Sales**: $0.4
- 📈 **First Profit**: $0
- 🎯 **Average Discount**: 15.62%
- 📦 **Total Quantity Sold**: 38K

### Visuals & Charts
- **Bar Chart**: Count of Sales by Sub-Category and Category
- **Clustered Bar Chart**: Product ID and Product Name count by Customer ID
- **Donut Chart**: Sales distribution by Category
- **Customer Table**: Customer names with their respective sales figures

### Navigation
- Side panel with buttons to toggle between:
  - Main Dashboard View
  - Detailed Analysis View

---

## 📊 Insights Derived

- **Top Categories**: Office Supplies and Furniture had the highest sales.
- **Customer Behavior**: Certain customers like *Aaron Bergman* had multiple transactions indicating potential for loyalty targeting.
- **Product-Level Trends**: Specific sub-categories and products contributed disproportionately to overall sales.
